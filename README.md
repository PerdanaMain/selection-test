# String Analysis Tool

A web application that compares two strings and calculates the percentage of characters from the first string that are present in the second string. Supports case-sensitive and case-insensitive modes, with a full history of past analyses.

## Features

- Analyze character match percentage between two strings
- Toggle between case-sensitive and case-insensitive comparison
- View, edit, and delete analysis history (in-memory, resets on restart)

## Design Patterns

**MVC (Model-View-Controller)** — routes delegate to static controller methods, which use model classes for business logic and render EJS views.

**Inheritance** — `AnalysisTask` extends `BaseTask`, which handles auto-incrementing IDs and creation timestamps via an abstract class.

**Static factory method** — `AnalysisTask.calculate()` is a pure static method that performs the character-matching algorithm, keeping it decoupled from instance state and easy to unit test.

**In-memory store** — analysis history is held in a module-level array in the controller. It is fast and simple but does not persist across server restarts.

## Algorithm

`AnalysisTask.calculate(input1, input2, isCaseSensitive)` iterates over each character in `input1` and checks whether it appears anywhere in `input2`. Match count divided by the length of `input1` gives the percentage.

```
percentage = (matchCount / input1.length) × 100
```

Example: `"ABBCD"` vs `"Gallant Duck"` (case-insensitive) → A✓ B✗ B✗ C✓ D✓ = 3/5 = **60.00%**

## Getting Started

### 1. Install dependencies

```bash
pnpm install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env` and set a port if needed (defaults to `3000`):

```env
PORT=3000
```

### 3. Run in development mode

Uses `nodemon` to watch for changes and restart automatically:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run in production mode

Compile TypeScript then start the compiled output:

```bash
pnpm build
pnpm start
```

## Running Tests

```bash
pnpm test
```

Tests are located in `src/__tests__/` and run with Jest + ts-jest (no compilation step required).

## API Routes

| Method | Path | Description |
|---|---|---|
| `GET` | `/` | Render dashboard with history |
| `POST` | `/analyze` | Submit two strings for analysis |
| `GET` | `/edit/:id` | Load a past task into the form for editing |
| `POST` | `/update/:id` | Recalculate and update a past task |
| `GET` | `/delete/:id` | Remove a task from history |
